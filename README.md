# Dholuo for Noela

A mobile-first app for learning Dholuo (Luo), starting with Kenyan Luo.

Run locally: npm run dev, then open http://localhost:8000

Publish: push to GitHub, then Settings > Pages > Deploy from a branch > main > / (root).

Install: open the live link in Chrome and choose Install app. On iPhone use Safari > Share > Add to Home Screen.

Content lives in js/data.js. Bump CACHE in sw.js whenever files change.
